# 字体风格选择(楷体/宋体)+ 词库子集化

## Goal

设置页新增「字体风格」选择:楷体(LXGW WenKai,现状)/ 宋体(霞鹜新致宋 屏幕阅读版),三端应用内生效;同时将全部内嵌字体按词库字符集子集化,移动端包体削减约 55MB。**无繁简转换**(源数据简体,动机为宋体审美,grill 已收敛)。

## 背景(grill 收敛 2026-08-10)

- 动机:古典宋体排版审美,非繁体显示;源数据简体,繁体显示需 OpenCC 文本转换(不做)
- 字体选型:霞鹜新致宋 屏幕阅读版(简体主库 8105 字 + IPAex 繁体打底,简体文本零缺字),优于繁体主库的 Chiron Sung HK
- 授权:IPA Font License v1.0(可商用,需保留授权文件)
- 词库唯一 CJK 字符:5275 个(实测)→ 子集化体积近似按 glyph 数比例

## 要求

| 项 | 内容 |
|---|---|
| 字体风格 | 设置页选项:楷体(WenKai)/ 宋体(新致宋),持久化,三端(Android/iOS/desktop)生效 |
| widget 标注 | 设置项标注「仅应用内生效」(widget 渲染在系统进程,无法用自定义字体,已实证) |
| 子集化 | 全部内嵌字体按词库字符集(5275 字 + UI 文本 + 标点)子集化;WenKai×2 + 新致宋 |
| 授权 | IPA Font License 授权文件入库 |

## Acceptance Criteria

- AC1:设置页可选楷体/宋体,切换即时生效并持久化(重启保留);三端渲染正确
- AC2:设置项带「仅应用内生效」标注
- AC3:子集化后字体渲染无缺字(词库全量抽样对比;UI 文本完整);桌面/移动端构建通过
- AC4:移动端包体显著下降(APK 体积对比:子集化前后)
- AC5:desktopTest 全绿

## 非目标

- 不做繁简转换(OpenCC)
- 不改 widget 字体(平台限制)
- 不引入新运行时依赖(子集化用 fonttools 本地脚本,不入依赖)
