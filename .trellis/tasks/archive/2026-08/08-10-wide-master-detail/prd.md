# 宽屏词牌/作者侧栏化(master-detail)

## Goal

宽屏(≥768dp)下,词牌页/作者页改为 master-detail 双栏:左侧列表常驻(浏览上下文),右侧并置所选词详情;选词为页面内部切换,不压栈。窄屏行为零变化。

## 交互模型

```
宽屏: 详情(全屏)→ 点词牌 → [词牌列表 | 当前词详情] → 点列表另一首 → 右侧原地切换
      → 返回 → 回全屏详情;作者链接 → 作者双栏页(压栈)
窄屏: 现状(全屏列表 → 点词 → openPoem 导航),零改动
```

## Acceptance Criteria

- AC1:宽屏词牌页/作者页双栏:左侧列表 + 右侧详情并置;点列表项右侧原地切换(不导航、不压栈)
- AC2:从详情点词牌/作者进入时,右侧初始显示当前词(无缝衔接);从索引/首页进入,右侧空态提示
- AC3:右侧操作区(收藏/作者/词牌链接)可用;词牌双栏内点作者 → 作者双栏页压栈
- AC4:返回 = 回上一页(全屏详情或来源);切 tab 内容层清除规则不变
- AC5:窄屏零回归(全屏列表 + openPoem 导航);desktopTest 全绿;双栏实机验收

## 非目标

- 不改窄屏路径、不改 openPoem/switchTab 语义、不引入新依赖
- 深链 songci://poem/{id} 仍进全屏详情(不进双栏)
