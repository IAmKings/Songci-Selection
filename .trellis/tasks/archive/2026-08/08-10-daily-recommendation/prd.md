# 首页每日推荐池(0点刷新+不重复+异常过滤)

## Goal

首页推荐改为「每日推荐池」:每日 0 点(或当日首次进入)从词库生成当天 20 首推荐(不重复、过滤异常词),当天固定;推荐池约 3 年全覆盖后重置循环。**widget 不参与**(维持现状随机/每小时刷新,已确认)。

## 背景(grill 收敛 2026-08-10)

- widget 独立池方案否决(4 套池复杂度 + 跨端体验割裂);widget 完全不动
- 标记法可靠:21340 首 / 20 首每天 ≈ 3 年全覆盖;池占满 90% 清空重置
- 异常过滤可落地:词牌 ⿰/超长、字体缺字、内容格式异常

## 要求

| 项 | 内容 |
|---|---|
| 每日池 | 每天 20 首,当天固定(0 点或当日首次进入生成);跨天自动换新 |
| 不重复 | 已推荐标记(推荐日期),抽样不放回;池满 90% 清空重置循环 |
| 异常过滤 | ① 词牌含 ⿰ 或 >12 字;② 内容含字体缺失字符(𠴇/𫍙 类,与子集化字体联动);③ 内容格式异常(无换行/超长单行/空白) |
| 首页展示 | 展示当日 20 首;跨 0 点(应用运行中)自动刷新 |
| widget | 不动(现状:随机 + 手动/每小时刷新) |

## Acceptance Criteria

- AC1:首页显示当日 20 首推荐,当天多次进入/切换一致;跨天自动换新(运行中跨 0 点自动刷新;重启后当日首次进入补生成)
- AC2:同一天内推荐不重复出现同一首;连续多天(模拟日期推进)无重复词(标记法生效)
- AC3:异常词(⿰ 词牌/超长词牌/缺字词/格式异常)不出现在推荐中
- AC4:desktopTest 覆盖:池生成确定性(同一天同池)、不重复、异常过滤、重置逻辑
- AC5:桌面运行目视验证:首页 20 首正常展示、跨天刷新

## 非目标

- 不改 widget(三端)
- 不做"已推荐"的 UI 展示(不显示推荐日期等)
- 不引入新依赖
