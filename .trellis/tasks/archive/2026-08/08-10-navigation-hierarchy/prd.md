# 导航分层重构(频道层/内容层分离)

## Goal

将导航重构为「频道层(tab)↔ 内容层(详情/词牌/作者)」两层模型:详情全屏凌驾 tab 之上;词牌/作者为内容层可逛子页;详情同层唯一(选词替换旧详情,不再循环入栈)。为平板展开(rail + 侧栏)建立干净的路由基础。

## 背景(grill-me 收敛 2026-08-10)

用户确认三个症状同根——导航无层级,所有页面平级混栈:

1. 详情(A) → 词牌 → 点同一首(A) → 详情(A) 无限循环(详情重复入栈)
2. 首页/收藏各进一个详情,tab 切换"两个详情并存"(tab 栈隔离,详情归属频道)
3. 详情/词牌/作者页底部 tab 常驻(详情未凌驾于频道层)

用户画像:进词牌/作者页是"**逛**"(因格律看同牌名他作 / 因词人看其他作品),选词后返回继续逛;喜欢再标记。→ 词牌/作者必须是**内容层可逛独立子页**。

## 目标模型

```
窄屏: tab(频道层)→ 详情(全屏盖 tab)→ 词牌/作者页(可逛,压栈)
      └→ 选词 = 替换详情帧(详情同层唯一,返回:词B详情→词牌→tab根,无循环)
宽屏(≥768dp): rail(频道)+ 详情区 + 词牌/作者侧栏(本任务只保证不回归,侧栏化后续)
```

## Acceptance Criteria

- AC1:详情/词牌/作者页隐藏底部 tab(窄屏),返回即回到频道层
- AC2:词牌/作者页选词 → 详情替换,返回路径 = 词详情 → 词牌/作者页 → 频道根;首页→详情→词牌→同一首词 不再产生重复详情栈
- AC3:tab 切换不再保留/并存详情(切 tab 放弃当前详情,回 tab 根)
- AC4:深链(小组件点击 songci://poem/{id})仍直达详情;详情返回行为不变
- AC5:宽屏(≥768dp)不回归;desktopTest 全绿
