# 随机宋词 · kami 手机/平板排版样式

## Goal

从 `db/songci.db` 随机抽取一首词，用 kami 的设计语言生成常见手机和平板尺寸的排版样式样例，作为后续 UI 设计的参考起点（参考样式，非最终产品界面）。

## Background / 已确认事实

- `db/songci.db`（SQLite，本仓库已有）：`poems` 21,050 首，`authors` 1,564 位；`poems` 字段为 `rhythmic`（词牌名）、`content`（全文）、`author_id`。随机抽取可用 `SELECT ... ORDER BY RANDOM() LIMIT 1`。
- `content` 以换行分隔韵句（每行一个韵句，句内用逗号/顿号），数据中没有显式的上阕/下阕结构标记。
- kami skill（`~/.claude/skills/kami/`）：暖羊皮纸 `#f5f4ed` 底、墨蓝 `#1B365D` 强调、衬线主导层级；中文使用 TsangerJinKai02（最佳努力）。模板在 `assets/templates/`，其中 `landing-page.html` 是唯一屏幕优先（浏览器）模板，其余均为文档/PDF 管线。
- kami 明确不做动态 Web App UI —— 本任务产出的是静态排版样例，在其能力范围内。

## Requirements

- **R1 随机取词**：从 `db/songci.db` 随机抽取 1 首词，并记录词牌名、作者、全文（可复现出处）。
- **R2 手机尺寸排版**：按 375×812（iPhone X 级，UI 设计常用基准）生成词作排版样式。
- **R3 平板尺寸排版**：按 768×1024（iPad 4:3，UI 设计常用基准）生成词作排版样式。
- **R4 视觉语言**：遵循 kami 设计语言（羊皮纸底、墨蓝强调、衬线层级、中文衬线字体）。
- **R5 交付说明**：交付物附一份简短说明（尺寸、所用字体、设计决策）。
- **R6 交付形态（已确认）**：HTML 固定视口页面 —— 每个尺寸一个独立 HTML，在浏览器中按精确设备尺寸打开/截图；不走 PDF 管线。
- **R7 交付位置**：样例与说明放入 `design/specimens/`（本仓库新目录）。

## Acceptance Criteria

- AC1：能从 `db/songci.db` 抽出一首真实存在的词（词牌、作者、全文与库中一致）。
- AC2：每个目标尺寸都有一个可打开查看的排版样例（手机 ≥1 个、平板 ≥1 个）。
- AC3：样例遵循 kami 视觉语言（底色/强调色/字体符合 R4）。
- AC4：说明文档列出所用尺寸与关键设计决策。

## Out of Scope（提案）

- 交互式 UI / 动态应用界面（kami 明确不做，且本任务只产出静态参考样式）
- 批量生成工具 / 可复用的排版生成器（本次先做单次流程，验证样式后再考虑固化）
- 收藏、搜索等产品功能

## 关键决策（已确认）

- 交付形态 = HTML 固定视口页面（非 PDF）—— 用户 2026-08-07 确认。
- 尺寸基准 = 手机 375×812、平板 768×1024（UI 设计常用基准，可在实现中微调）。
- 先做单次流程，不固化生成工具。
