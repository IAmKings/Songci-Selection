# 宋词排版样式样例(kami 设计语言)

随机抽取一首宋词,用 kami 设计语言生成手机 / 平板尺寸的静态排版样式,作为后续 UI 设计的参考起点。

## 素材出处

- 来源:`db/songci.db`(poems 表,21,050 首)
- 抽取:随机 + 过滤残缺片段(数据源含 `……` 的碎片不参与)
- 本次抽中:`poems.id = 13284`

| 字段 | 值 |
|---|---|
| 词牌 | 贺新郎 |
| 作者 | 戴复古 |
| 全文 | 蜗角争多少。是英雄、割据乾坤,到头休了。一片泥涂荒草地,尽是鱼龙故道。新堤上、风涛难保。沧海桑田何时变,怕桑田、未变人先老。休为此,生烦恼。讼庭不许频频到。这官坊、翻来覆去,有何分晓。无诤人中为第一,长讼元非吉兆。但有恨、平章不早。尊酒唤回和气在,看从来、兄弟依然好。把前事,付一笑。 |

## 交付物

| 文件 | 尺寸 | 版式 |
|---|---|---|
| `phone.html` | 375 × 812(iPhone X 级) | 单栏,标题 + 上下阕纵向留白 |
| `tablet.html` | 768 × 1024(iPad 4:3) | 双栏,上下阕并置,中缝细线 |

查看方式:浏览器直接打开;用 devtools 设备模拟到对应尺寸即为全幅效果(深灰背板是衬托样张,不在样张内)。

## 设计决策

- **视觉语言**:kami token(取自 `landing-page.html`)—— 羊皮纸底 `#f5f4ed`、墨蓝强调 `#1B365D`、衬线层级;不用纯白、不引入第二种强调色。
- **字体**:中文衬线 `TsangerJinKai02`(仓耳今楷,CDN)+ 系统回退 `Songti SC` → `serif`;页脚标注用 `PingFang SC`。
- **韵句节奏**:每韵句独立成行(数据以换行分隔,无阕标记);上下阕分栏点按全词中点划分,本词 6+6 恰好为真实分阕处。
- **布局差异**:手机单栏纵向流,紧凑省空间;平板双栏并置,利用宽度呈现上下阕对读。
- **无图片/无多余元素**:纯文字排版,保持样张可直接作为 UI 设计的排版与配色参考。

## 复现抽取

```bash
sqlite3 db/songci.db \
  "SELECT p.rhythmic, a.name, p.content FROM poems p
   LEFT JOIN authors a ON a.id=p.author_id
   WHERE p.content NOT LIKE '%……%' AND length(p.content) BETWEEN 80 AND 300
   ORDER BY RANDOM() LIMIT 1;"
```
